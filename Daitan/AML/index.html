AML Design System

The design system I created with other designers for AML, an application a bank uses to be alerted about fraud and money laundering. Alerts, cases and big tables need an interface that stays calm, so the system sets the colours, type, icons and components that every screen is built from.

In short

The result: the client fully adopted the system. The stakeholder and the end users reported that it vastly improved the usability of the tool, and the developers described the handoff as exceptional.

The scope: three designers delivered the whole system redesign, with the prototype implemented in Sketch for the developers' handoff, in one week. That is a very large scope for such a short time.

Why it mattered: it saved a lot of time and discussion afterwards. When the client asked about structure or design choices, we pointed to the approved design system.

Design pillars

01

Colours named by role

Every colour is a $name with weights from 900 to 50, where 500 is the base. The number makes it easy to document the states of a component, such as a button or a link.

02

Rules beside every component

Each page says what a component is for, shows its states (regular, hover, clicked, disabled) and measures it, so engineers and designers read the same thing.

03

One grid

Spacing follows the 8-point grid (24, 16, 8, 4 and 2 px), and the specs paint every margin in colour so it can be checked at a glance.

04

Made for risk and dense data

Alert red, yellow and green for risk level, fraud status icons, small fields for fraud tables and pagination, and a search engine for big tables.

Typography

Two typefaces, a short size scale and header styles with their spacing.

Two typefaces

Lato for text and Montserrat for headings and buttons, taken from the product’s branding guidelines. The default size is 13px for body text, and the smallest is 11px, used on small buttons.

  • Sizes: small 11px, regular 13px, medium 16px, large 18px, xl 24px, xxl 36px (legacy)
  • Line height: 1.2 regular, 1.7 for long text
  • H1 for page titles in Luxor, H2 for sections and drawers, H3 for subsections and modals

Icons

One icon library, one pattern and a sizing rule.

One library, one pattern

Icons come from the free Font Awesome set. Each one fills a 16×16 px area, with the icon at 14×14 px and 2px of padding, and takes the colour of its context.

  • Sizes follow the font sizes: regular, large, xl and xxl
  • Application icons for actions, direction, objects and status, each with its name, code and where it is used
  • Check and exclamation are reserved for form and toast feedback
  • A separate set for Link analysis and five icons for fraud status: viewed, not viewed, dismissed, case created, case closed

Buttons

Six types, with guidelines for labels and measured specs.

Six types, four states

Primary, secondary, warning, flat, menu, icon and link. Each is shown regular, on hover, clicked and disabled.

  • Primary: the main action, only one per context or none. Orange by default, green for a positive action
  • Secondary: when every action on a page has the same weight
  • Small buttons: when a regular one does not fit; icon buttons: 16×16 with a tooltip

Label guidelines

  • Keep the call to action short
  • Name the button after what it does
  • Do not use punctuation
  • Avoid generic labels such as “Ok”

Structure

Montserrat Bold, uppercase, 13px. Width follows the content up to 256px, then the label is cut with an ellipsis and a tooltip on hover. The spacing was reduced to 16px to follow the 8-point grid.

Input fields

The fields people fill in all day: states, specific fields and spacing.

The soul of the system

Forms are the main interaction and input. A field has a label and help text, and the label and placeholder are written in capitals at the start.

  • States: regular, hover, active, required, disabled and error
  • The “x” to clear shows on hover and stays while the field is active; in the error state it is always visible
  • Small fields are used in fraud screens and in pagination

Specific fields

  • Password: masks every character
  • Currency: commas appear while typing, and a digit placeholder shows on the right
  • Timestamp: HH:MM:SS, six digits, the colons appear on their own
  • Textarea: for long text and alert notes

Specs

Fields are 192px wide at minimum and 408px at most, Lato 13px, with an 11px label and a 1px border. Fields are 16px apart horizontally and 24px vertically; a long label is cut with an ellipsis and a tooltip.

Search engine

A pattern for finding records in big tables.

Regular and advanced

Search finds specific information in the columns of a table. The regular search shows the four most important fields; the advanced search adds the rest of the searchable columns in a four-field grid, and pushes the table down when it opens.

  • With fewer than four fields, there is no advanced search
  • Show Results is the primary button and Clear All the secondary one
  • With the advanced search closed, a count shows how many parameters are filled
  • Placement is shown with and without the sidebar
