Earlier work at Daitan

My years at Daitan Group, where I focused on the craft and the systems behind interfaces. I worked on design systems and Sketch libraries, on mockups across many tools, and on a variety of projects for different clients, always with the engineering team so the design was implemented correctly.

Projects

I worked on many projects at Daitan, not only AML. The AML design system has its own case study; the others are summarised here.

AML design system

A design system I created with other designers for AML, an application a bank uses to be alerted about fraud and money laundering: colours, typography, icons, buttons, input fields and search.

Mar 2018 – Jun 2019 · Sketch · Zeplin. I moved the design project from Photoshop to Sketch with developer handoff in Zeplin, took many features from low to high fidelity with screen flows presented to the client, and wrote a framework of every element and its interactions to keep the complex interface consistent. The team worked in SCRUM.

Open the case study →

Call center and VoIP agent interfaces

An interface agents in call centers use to manage calls, messages and other ways of talking to their clients. I worked on a redesign, with libraries in Sketch and InVision prototypes for user testing, and in parallel on a reskin that moved every element to the company's new design language.

Nov 2017 – Feb 2018 · Sketch · InVision

Biometric and clearance project for airports

An identification totem that lets passengers move past boarding lines with their biometrics and boarding pass, plus a log interface where an ambassador checks that everything is in order and accompanies them to the gate. I redesigned the ambassador UI and created another use case for it with a Design Sprint, with a working prototype.

Jun 2019 – Aug 2019 · Sketch · InVision

Bank SMS management and database capacity interfaces

The SMS interface organises message data so a bank can act on the cost of messages, such as repeated messages or numbers that were cancelled. The capacity interface uses dashboards to predict when machine parts reach end of life, so they can be ordered in time to avoid downtime. I improved the first and created the second from the bank's branding and the work of the front-end, back-end and data science teams.

Jun 2019 – Sep 2019 · Figma

Learning tool and assessment tool for a software company

A learning tool that guides new users through the company's software with articles, hands-on experiences and tutorials, and an assessment tool that checks whether a client's database hardware is compatible with the company's virtual machine software, then suggests upgrading the machines, moving to the company's cloud, or upgrading the software. I migrated the project from Sketch to Adobe XD, defined features and UI decisions in an agile process, and proposed user and benchmark research.

Sep 2019 – Mar 2020 · Figma · Adobe XD

Telecom project for transferring or adding users

A flow for transferring or adding users to a telecom client's platform, with low fidelity prototypes in Axure and high fidelity in Sketch.

Apr 2020 – Jul 2020 · Axure · Sketch
