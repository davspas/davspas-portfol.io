Projetos

Trabalhei em muitos projetos na Daitan, não só no AML. O design system do AML tem seu próprio estudo de caso; os demais estão resumidos aqui.

Design system do AML

Um design system que criei com outros designers para o AML, uma aplicação que um banco usa para receber alertas de fraude e lavagem de dinheiro: cores, tipografia, ícones, botões, campos de entrada e busca.

mar 2018 – jun 2019 · Sketch · Zeplin. Migrei o projeto de design do Photoshop para o Sketch, com handoff para os desenvolvedores no Zeplin, levei várias funcionalidades de baixa a alta fidelidade com fluxos de tela apresentados ao cliente e escrevi um framework com todos os elementos e suas interações para manter a consistência da interface complexa. A equipe trabalhava em SCRUM.

Abrir o estudo de caso →

Interfaces de call center e VoIP

Uma interface que os agentes de call centers usam para gerenciar chamadas, mensagens e outros meios de falar com seus clientes. Trabalhei em um redesign, com bibliotecas no Sketch e protótipos no InVision para testes com usuários, e em paralelo em um reskin que levou todos os elementos para a nova linguagem de design da empresa.

nov 2017 – fev 2018 · Sketch · InVision

Projeto de biometria e liberação em aeroportos

Um totem de identificação que permite aos passageiros passar pelas filas de embarque com biometria e cartão de embarque, mais uma interface de registro em que um embaixador confere se está tudo certo e acompanha o passageiro até o portão. Redesenhei a UI do embaixador e criei outro caso de uso para ela com um Design Sprint, com um protótipo funcional.

jun 2019 – ago 2019 · Sketch · InVision

Interfaces de gestão de SMS e capacidade de banco de dados de um banco

A interface de SMS organiza os dados das mensagens para que o banco aja sobre o custo, como mensagens repetidas ou números cancelados. A interface de capacidade usa dashboards para prever quando peças de máquinas chegam ao fim da vida útil, para que possam ser pedidas a tempo e evitar paradas. Melhorei a primeira e criei a segunda a partir da marca do banco e do trabalho das equipes de front-end, back-end e ciência de dados.

jun 2019 – set 2019 · Figma

Ferramenta de aprendizado e de avaliação para uma empresa de software

Uma ferramenta de aprendizado que guia novos usuários pelos softwares da empresa com artigos, experiências práticas e tutoriais, e uma ferramenta de avaliação que verifica se o hardware de banco de dados de um cliente é compatível com o software de máquinas virtuais da empresa, e depois sugere atualizar as máquinas, migrar para a nuvem da empresa ou atualizar o software. Migrei o projeto do Sketch para o Adobe XD, defini funcionalidades e decisões de UI em um processo ágil e propus pesquisas com usuários e benchmark.

set 2019 – mar 2020 · Figma · Adobe XD

Projeto de telecom para transferir ou adicionar usuários

Um fluxo para transferir ou adicionar usuários à plataforma de um cliente de telecom, com protótipos de baixa fidelidade no Axure e de alta fidelidade no Sketch.

abr 2020 – jul 2020 · Axure · Sketch
