Unity Character

A Character Viewer panel for the Unity editor. Load a sprite character, look at it from one, two, four or eight sides, animate it, recolour every part and save or export the result, without leaving the editor.

Design pillars

01

One panel, one character

Files, avatar, character and view settings stack in one dockable window, each a foldout, so the artist can hide what they are not using and keep the character in view.

02

Native to Unity

Dark grey surfaces, foldout headers, segmented buttons, colour bars with an eyedropper and a plain checkbox. It borrows Unity’s own controls so nothing needs to be learned twice.

03

Say it on hover

Labels stay short. A fixed information box at the end of each section explains whichever field the pointer is on, so the panel stays compact and still teaches itself.

04

Show the result first

The character is the biggest thing in the panel. Pose count, views and colours change it immediately, and idle, walk and attack animations run in every view.

Two iterations 2 versions

The first pass used the full verbs (“Download”, “Import Sprites”) and kept every foldout open. The second shortens the labels, because the foldout title already says “Prefab” or “Sprites”, and collapses Avatar View and Character View to give the settings room.

Hover information 1 sheet

Every control has a one-line explanation, written for people who have never used the tool. The sheet is the copy deck for the information box.

Live prototype

The Character Viewer panel inside a mock of the Unity editor. It works: the character is drawn live, and everything in View Settings changes it.

Character Viewer

Opens full screen. The editor around the panel is a static mock.

Switch between one, two, four and eight poses, choose views, animate Idle, Walk and Attack, recolour each part, save colours in your browser, and create or export the character.

Open the prototype →
Tips. Hover any field to read what it does. Click a foldout title to collapse it. Upload, Create, Import, Open and Export are simulated: they show what Unity would do and never read or write files. Colours can be saved in your browser. Best on a desktop screen.
